# DoorSense demo and submission

The current demo has two scenarios: recognize one parent-enrolled Family member,
then delete the reference and show the same clear face become Unknown. Child
safety mode gates the camera banner and child recommendation.

- [Demo runbook](DEMO_RUNBOOK.md): short problem statement, startup and live sequence.
- [Submission draft](SUBMISSION_DRAFT.md): approved description, technical disclosure
  and focused roadmap; required repository/video/social fields still need actual URLs.
- [Technical overview](../docs/TECHNICAL_OVERVIEW.md): what works now and how.
- [Acceptance checklist](../docs/DEMO_AND_ACCEPTANCE.md): verification still needed.

Use real camera observations and the displayed measured distance. Sensor activity
simulations, manual identity labels and separate analysis tabs are superseded.
A public repository, recording, social post and submitted entry must each be
verified separately; preparation does not establish publication or submission.
